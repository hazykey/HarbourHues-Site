To publish, from any device:
  1. Hit Copy HTML, then open the repo on GitHub and choose Add file → Create new file.
  2. Name it client-downloads/SLUG/index.html. Typing the slashes creates the folders.
  3. Paste, commit to main. GitHub Pages serves it in about a minute.
On a computer you can use Download HTML instead and drop the file into client-downloads/SLUG/index.html locally.
